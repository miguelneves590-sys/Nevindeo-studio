# Nevindeo icon

The icon is the artwork supplied by the project owner (`nevindeo_icon_original_1024.jpg`),
with rounded corners applied. It is rendered to:

- `src/crates/concat-android/res/mipmap-*/ic_launcher.png` (48/72/96/144/192 px): the Android launcher icon
- `assets/icons/nevindeo_logo_{16..512}.png`: window and desktop icons
- `assets/icons/nevindeo.ico`: the Windows icon (16 to 256 px)

The original Concat artwork is kept untouched under `assets/`.
